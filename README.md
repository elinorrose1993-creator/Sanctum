# Sanctum — your copy 🏛️

Hi! This is a complete, working copy of the **Sanctum** website prototype. It's yours to open, run, and change however you like. No installing, no accounts — it's just files.

---

## 1. See it working
Double-click **`index.html`** — it opens in your web browser. Click **"Enter"** to go in, then click around (browse therapists, filter them, open a profile, the support chat, etc.). It uses example data, so nothing is connected to anything real.

> Tip: it looks best on a laptop/desktop browser, and connect to wifi so the proper fonts load.

---

## 2. Make it your own with Claude Code
1. Open **Claude Code** on your laptop.
2. Open **this folder** in it (so it can see `index.html`, `styles.css`, `app.js`).
3. Paste the prompt below as your **first message**, then just ask for changes in plain English.

### 👉 Paste this into Claude Code first
```
This folder is "Sanctum", a self-contained HTML/CSS/JS website prototype
(index.html, styles.css, app.js — no build step, no dependencies). Please
read all three files plus CLAUDE.md so you fully understand how it works,
then give me a short plain-English summary of what it is and how it's put
together. Don't change anything yet — just get familiar with it and tell me
how to preview it. After that I'll ask you to help me customise it.
```

Then ask for whatever you want, e.g.:
- "Change the name from Sanctum to **[your name]** everywhere."
- "Make the gold accent colour a deep green instead."
- "Rewrite the homepage text for **[my topic]**."
- "Add three more therapists to the directory."
- "Change the logo to something simpler."

---

## 3. Good to know
- **Nothing to install** — it's just three files plus these notes.
- **Refresh the browser** after any edit to see the change.
- **`CLAUDE.md`** in this folder is a technical rundown — your Claude Code reads it automatically, and you can peek at it too.
- It's a **prototype** (front-end only). When you're ready for real accounts, logins and payments, that's a separate "make it a real app" step Claude can help with later.

Have fun with it! 💛
